# Pura Ruta Guide

Primera versión funcional de la guía turística de Costa Rica, creada con Expo y React Native.

## Probar gratis en tu teléfono

1. Instala **Node.js LTS** desde https://nodejs.org.
2. Instala **Expo Go** desde la Play Store o App Store.
3. En una terminal, dentro de esta carpeta, ejecuta:

   ```powershell
   npm install
   npm start
   ```

4. Escanea con Expo Go el código QR que aparecerá.

No necesitas una cuenta de pago. Mantén el teléfono y la computadora conectados a la misma red Wi-Fi.
